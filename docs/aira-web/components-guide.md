# AIRA Web Components Guide

`aira-web-components` is a plain Java library for rendering the common AIRA application shell around servlet-generated page content.

It does not provide a base servlet and does not render page-specific business components. Applications keep their own servlet classes and compose `AiraPage` where they write the response.

## Core Types

- `AiraPage` - document and shell renderer.
- `AiraLogo` - optional approved logo asset.
- `AiraActionItem` - global action link rendered as a button-style link.
- `AiraSearchConfig` - optional global search form.
- `AiraAccountConfig` - optional account/sign-in area.
- `AiraEnvironmentConfig` - optional non-production badge.
- `AiraContextConfig` - optional contextual title and navigation.
- `AiraNavigationItem` - contextual navigation link with active/current state.
- `AiraFooterConfig` - optional footer URL/year overrides.

## Default Resource Constants

`AiraDefaults` includes constants for public resource paths so applications do not need to hard-code filenames:

- `AiraDefaults.STYLESHEET_PATH` - `/aira/css/aira.css`
- `AiraDefaults.DEFAULT_LOGO_PATH` - `/aira/images/AIRA_2018Logo_BlueGreen_Hor.png`
- `AiraDefaults.DEFAULT_LOGO_ALT_TEXT` - `American Immunization Registry Association`

The `AiraPage` renderer uses `AiraDefaults.STYLESHEET_PATH` automatically. Applications should use `AiraDefaults.DEFAULT_LOGO_PATH` when they want the packaged default logo.

## Example

```java
AiraPage page = AiraPage.builder()
    .applicationName("Example Application")
    .applicationSubtitle("Operational workspace")
    .applicationVersion(applicationVersion)
    .documentTitle("Dashboard")
    .contextPath(request.getContextPath())
    .identityHref("/")
    .logo(new AiraLogo(AiraDefaults.DEFAULT_LOGO_PATH, AiraDefaults.DEFAULT_LOGO_ALT_TEXT))
    .addGlobalAction("Explore", "/", "secondary")
    .search(new AiraSearchConfig("/search", "q", "Search", "Search records"))
    .account(new AiraAccountConfig("Signed in user", "Account", "/account"))
    .environment(new AiraEnvironmentConfig("Local", "Local development environment"))
    .context(new AiraContextConfig("Program Area", List.of(
        new AiraNavigationItem("Home", "/", true),
        new AiraNavigationItem("Reports", "/reports", false))))
    .addLocalStylesheet("/css/application.css")
    .build();

page.writeStart(writer);
renderApplicationContent(writer);
page.writeEnd(writer);
```

## Logo Behavior

`AiraLogo` is optional. If omitted, the shell renders a compact text placeholder so the header remains structurally valid. For real application pages, configure an approved logo:

```java
.logo(new AiraLogo(AiraDefaults.DEFAULT_LOGO_PATH, AiraDefaults.DEFAULT_LOGO_ALT_TEXT))
```

The logo source is resolved through the configured servlet context path. With a context path of `/hub`, the default logo is requested from:

```text
/hub/aira/images/AIRA_2018Logo_BlueGreen_Hor.png
```

Use concise alt text that identifies the organization. The default constant is appropriate for the packaged horizontal AIRA logo.

## Output Responsibilities

The renderer writes:

- HTML document start and metadata.
- Shared `aira.css` link before local stylesheets.
- Skip link.
- Global header and optional header controls.
- Optional contextual title/navigation with `aria-current`.
- Opening `main` element.
- Optional page heading and intro.
- Closing `main`, required institutional footer, and document end.

Applications write everything inside `main`.

## Escaping

All text and attribute values accepted by the shared renderers are escaped. The library accepts plain text for its own fields; it does not sanitize arbitrary HTML generated by applications.

Applications remain responsible for safely generating and escaping their page-specific content.

## Context Paths

Pass `request.getContextPath()` to `contextPath(...)`. Application-relative paths such as `/css/application.css`, `/reports`, and `/` are resolved correctly for both an empty context path and a deployed context path.

Absolute `http://` and `https://` URLs are left unchanged. Fragment links such as `#section` are left unchanged.

## CSS Components

The renderer only emits the shell. Page content should use the shared `aira-` CSS classes directly. First-release CSS categories include:

- Layout primitives.
- Typography and page headers.
- Buttons and actions.
- Forms and selection controls.
- Badges, tags, and statuses.
- Cards, panels, choice rows, and empty states.
- Event lists.
- Tables.
- Alerts.
- Management sidebars/layouts.
- Utilities.

## Deliberately Not Included

This release does not include shared JavaScript, menus, dialogs, bottom sheets, drag-and-drop, authentication hooks, session handling, data-grid renderers, or domain-specific component renderers.
